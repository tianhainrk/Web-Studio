AnPinime Research / DramaBox 7.0.1

DramaBox API Tester

Kiểm thử thủ công 14 endpoint dựa trên báo cáo REA. Chọn API, sửa request JSON và xem phản hồi thực tế. Trang này gửi từng request qua backend Vercel đã đăng nhập, không tự động quét hoặc chuyển tiếp token. Có thể đọc HTTP status thực từ DramaBox ngay cả khi trình duyệt bị CORS.

Trạng thái nguồn: 14/14 endpoint mới được xác định bằng phân tích tĩnh; chưa có endpoint nào được xác minh trả dữ liệu thành công. REA và phép thử thực tế đều ghi nhận Akamai trả HTTP 403 Access Denied. Server Vercel không thể tự mở khóa lớp bảo vệ này. Phần 4 bên dưới cho phép thử metadata từ nhà cung cấp khác. Vercel không tạo chữ ký sn/tn nên HTTP 403 vẫn có thể xảy ra. Không dùng để vượt xác thực, DRM hoặc quyền xem trả phí.

1 · Tạo yêu cầu

Giá trị bookId/chapterId minh họa lấy từ báo cáo REA, không phải ID đã xác minh live. Chỉnh theo dữ liệu thật nếu có.

Chế độ chẩn đoán an toàn chỉ gửi request không có token. Đăng nhập tài khoản quản trị PineDrama-Web-Studio ở trang chủ trước khi thử. Proxy không hỗ trợ nhập hoặc chuyển tiếp sn/tn.

2 · Kết quả

Chưa gửi— ms—
Chọn endpoint rồi nhấn “Gửi POST” để kiểm thử.

Request được gửi qua backend Vercel cùng tên miền. Nếu DramaBox từ chối, trang sẽ hiển thị HTTP 403/401 và nội dung trả về. Cần đăng nhập trang chủ PineDrama-Web-Studio trước.

Nếu nhận HTTP 403, ghi nhận API bị từ chối trong ngữ cảnh kiểm thử; không suy ra endpoint không tồn tại.
Giải thích lỗi

HTTP 200: server trả response; kiểm tra tiếp status trong JSON, mã HTTP 200 chưa chắc thành công nghiệp vụ.

HTTP 401/403: thiếu quyền, phiên, chữ ký, hoặc WAF từ chối.

Vercel HTTP 401: chưa đăng nhập website. Vercel HTTP 502: proxy không kết nối được hoặc upstream timeout. DramaBox HTTP 403: WAF hoặc xác thực DramaBox từ chối.

Timeout: chưa nhận phản hồi trong thời gian đã chọn, không phải kết luận endpoint hỏng.

3 · Danh sách tập DramaBox

Hiển thị tất cả tập được API trả về, gồm tập miễn phí, đã mua và tập khóa. Nhãn khóa chỉ là metadata; việc phát video vẫn cần quyền do DramaBox cấp.

Nút này dùng endpoint /drama-box/chapterv2/list qua proxy Vercel đang có. Nếu DramaBox trả HTTP 403, danh sách không thể tải được từ máy chủ.

Dán JSON phản hồi hợp lệ để phân tích ngoại tuyến
Tổng tập: —Có quyền: —Đang khóa: —
Chưa có dữ liệu. Nhập Book ID và thử tải, hoặc dán response JSON hợp lệ.

4 · Nguồn metadata bên thứ ba (chưa xác minh hoạt động)

DramaBox+ API — bên thứ ba, không thuộc DramaBox. Nguồn này công bố API thử nghiệm để tra cứu danh mục và chi tiết phim. Đây không phải cách mở khóa API chính thức; thông tin từ nguồn này chưa được xác minh độc lập.

Chỉ gửi dữ liệu tìm kiếm hoặc ID phim khi bạn nhấn nút. Không gửi token, cookie, mật khẩu; không lấy video trả phí. Có thể gặp lỗi 401/429 hoặc nhà cung cấp ngừng dịch vụ.

Chưa gửi yêu cầu.
Kết quả JSON của bên thứ ba sẽ xuất hiện ở đây.

Tham khảo tài liệu DramaBox+ API. Nguồn này có thể đã đổi địa chỉ hoặc bỏ trial key công khai. Nếu nhận 401/403/404, website không thể tự sửa quyền truy cập của nhà cung cấp. Không nhập API key bí mật ở trang web.

Nguồn: 02-DRAMABOX-API-CONTRACT.md và dramabox-contract.json (REA, 2026-11-03). Mỗi endpoint đều có STATIC_CONFIRMED / BLOCKED_BY_AUTH theo báo cáo. Trang không dùng khóa RSA, không tạo hoặc chuyển tiếp header sn/tn, không thay đổi quyền tập phim. Tất cả phép thử qua Vercel yêu cầu đăng nhập website và bị giới hạn vào 14 endpoint cho sẵn.
